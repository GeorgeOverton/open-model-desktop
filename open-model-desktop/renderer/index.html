New to this? What the words mean

"4B" means 4 billion parameters. Bigger is usually smarter but needs more memory and runs slower. "Q4_K_M" is a compressed version of the model. It's the recommended balance of size and quality for most people, and the app picks it for you.

Memory: we've guessed your computer's memory below. On a Mac with Apple Silicon (M1 to M4) that's all you need. On a PC with an NVIDIA or AMD graphics card, models run fastest when they fit in the card's memory, but they still work using normal memory (slower).

Greyed out models are too big for the memory you picked, so they're listed last.

Amazon Alexa

Say "Alexa, ask my computer what's a good name for a cat?" and a model on this PC answers through your Echo. It needs your own free Alexa skill and a free ngrok tunnel so Amazon can reach this PC. It takes about 15 minutes to set up once: follow the steps below.

Setup steps
  1. ngrok (the tunnel). Make a free account at . Copy Your Authtoken and paste it above. Under Domains, claim your free static domain and paste it above. Install ngrok: in Windows Terminal type winget install ngrok.ngrok, or download it from and put ngrok.exe's location in the box above.
  2. Tick Let Alexa use my models. The status should say Online with your address.
  3. The skill. Open the and sign in with the same Amazon account as your Echo (it's free). Press Create Skill: any name, Other → Custom model, Provision your own hosting, Start from scratch.
  4. In Build → Interaction Model → JSON Editor, delete what's there, press Copy skill setup above and paste it. Press Save, then Build skill.
  5. In Build → Endpoint, choose HTTPS. Press Copy endpoint address above and paste it into Default Region. For the certificate, choose "My development endpoint is a sub-domain of a domain that has a wildcard certificate from a certificate authority". Press Save.
  6. Copy the Skill ID shown on that page (it starts amzn1.ask.skill) and paste it above.
  7. Open the Test tab and switch testing to Development. Type "ask my computer what is two plus two" to try it, then say it to your Echo.

Alexa waits about 8 seconds for an answer. If a model takes longer, Alexa says it's still thinking: say "what's the answer" a few seconds later. Say "start over" for a new conversation. Your PC must be on with the app open. Only your own skill is let in: every request is checked for Amazon's signature and your skill ID. Alexa chats are saved in Saved chats (they start with 🔊).

Running models

Then Chat and each wake phrase can use a different model without waiting for it to load again. If a new model doesn't fit, the app stops the one you used longest ago (never one that's answering) and tells you. Untick this to run only one model at a time, which is gentler on smaller computers.

Saved chats

When you ask any model for a file, the app asks before saving it in Documents › Open Model Desktop (a folder for each chat), and asks again before opening one that would run on your computer. Pressing "Always" on a file turns on the boxes above; untick them to be asked again. Deleting a chat keeps its files.

Every conversation in Chat is kept in a folder on this computer, so you can open it again from the list on the left of Chat. Nothing is uploaded. Voice mode conversations are saved too (they start with 🎙️).
